CampusConnect — 校园网自动认证
==============================

适用：本校 ePortal（门户 http://10.130.128.9）
系统：Windows 10 / 11，无需管理员权限，无需安装 PowerShell 7。

一、使用（免安装）
------------------
1. 解压整个文件夹（不要只复制某一个文件）。
2. 双击“CampusConnect.vbs”打开图形界面（无控制台；
   “CampusConnect.cmd”也可，cmd 窗口会闪一下）。
   高分屏会自动缩放，不用手动设置。
3. 首次使用：在“设置账号”里输入学号和密码，保存。
4. 勾选“开机自启”（可选），点“启动”。
5. 之后正常使用即可：Windows 负责连接 WiFi，工具只在当前 WiFi
   需要认证时自动登录；不需要认证的 WiFi 会被记录，下次跳过。

二、界面按钮
------------
- 启动 / 停止 / 重启：控制后台守护进程。
- 设置账号：修改学号、密码、门户地址（密码 DPAPI 加密）。
- 查看日志：打开 rea-daemon.log。
- 打开目录：打开本文件夹。
- 开机自启：登录 Windows 时自动启动。
- 停用/卸载：停止守护、移除开机自启；之后可直接删除整个文件夹。
- 退出：只关闭窗口，不停止后台守护。

三、WiFi 认证怎么工作
--------------------
不主动连接/切换 WiFi；Windows 负责连接，工具只检查当前连接。
守护进程只在遇到新的 SSID 时探测一次：
  - 302 / 200+JS 跳学校门户 → 需要认证，自动登录
  - 204 / 正常内容          → 不需要认证，记入 wifi-cache.json，下次跳过
  - 超时 / 无响应            → 内网（SCUJJ-IT-1/2 这类会记入并跳过）
名称包含 SCJJXY 的会作为认证候选。不需要知道其他认证 WiFi 的名称。
想重新检测某个 SSID：删掉本目录里的 wifi-cache.json 即可。

四、安全说明
------------
- 密码用 Windows DPAPI 加密，绑定当前 Windows 用户；换用户/换机器无法解密。
- 门户本身是 HTTP，密码在校园网内是明文传输；请勿把本工具用于他人账号。
- 本工具仅维持本人账号的正常在线状态，不绕过任何访问控制策略。

五、常见问题
------------
- 提示“requires version 5.1”：用 Windows 自带的 powershell.exe 运行
  CampusConnect.vbs（双击即可）。
- 登录失败：先确认能打开 http://10.130.128.9；如果开了 Clash/TUN，先关闭或给
  10.130.128.9 加 DIRECT 规则。
- 守护不认证：确认当前 WiFi 确实需要认证；删掉 wifi-cache.json 重新检测；
  再看 rea-daemon.log。
